# Hồ sơ máy

Mỗi máy dùng ID ổn định của xưởng, ví dụ MC-001. Tên FANUC 0i-MF hoặc Okuma OSP-P300M là controller, không đủ nhận diện máy vật lý.

Copy _template-machine.md cho máy mới. Ghi UNKNOWN cho dữ liệu chưa xác định; không suy ra M-code từ hãng controller. Mỗi dữ liệu quan trọng cần manual/trang hoặc người/ngày xác nhận.
