# Phát hành

Chưa có release approved. Không dùng template hoặc source draft cho sản xuất.

Mỗi release cung cấp CPS và dependency nếu có, ID máy, version/hash, upstream, properties/cấu hình, phạm vi sử dụng, hướng dẫn cài, thay đổi hoặc ghi rõ `baseline` không custom logic, bằng chứng và người/ngày duyệt. Baseline vẫn là release theo đúng máy sau khi được test/review; upstream chỉ là nguồn nền. Có thể lưu manifest ở đây và gói trên GitHub Releases khi được yêu cầu.

Không ghi đè release cũ. Rollback dùng release custom đã duyệt cho đúng máy; upstream không tự được duyệt.
